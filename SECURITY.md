# Security Policy

## Xavfsizlik muammosini xabar qilish

Xavfsizlikka oid muammoni public issue’da e’lon qilmang. GitHub’dagi **Private Security Advisory** orqali qisqa, qayta tiklanadigan tavsif bilan yuboring.

Hisobotda muammo ta’siri, qayta tiklash qadamlari, tegishli URL yoki komponent va ehtimoliy yechim bo‘lsa, uni yozing. Token, cookie, parol, shaxsiy ma’lumot yoki production ma’lumotlarini yubormang.

## Javob berish tartibi

Hisobotlar imkon qadar tez ko‘rib chiqiladi. Muammo tasdiqlansa, tuzatish private tarzda tayyorlanadi, tekshiriladi va kerak bo‘lsa release notes’da umumiy mazmunda qayd etiladi.
