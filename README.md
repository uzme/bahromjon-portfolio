# Bahromjon Mengliyev — Portfolio

An editorial developer portfolio for **AI products, web applications, secure integrations, and automation**.

## What this portfolio communicates

The site uses the **Signal Ledger** design system: a warm editorial canvas, Verdigris Teal quality signals, and project pages that emphasize evidence such as live demos, CI, security, and technical decisions.

## Local development

```bash
pnpm install
pnpm dev
```

Run validation before merging:

```bash
pnpm check
pnpm build
```

## Technology

React 19, TypeScript, Vite, Tailwind CSS 4, and Lucide icons.
